# PetPulse mini

Учебное приложение на Node.js + Express — мини-версия программного комплекса PetPulse
для учёта домашних питомцев и каталога ветеринарных врачей.

Состоит из двух частей:
- `server/` — сервер с API;
- `client/` — страница, которая отправляет запросы на сервер.

Данные хранятся в памяти сервера (в массивах) и сбрасываются при перезапуске.

## Запуск

1. Сервер:

```shell
cd server
npm install
npm start
```

Сервер запустится на http://localhost:3001.
Режим `npm run dev` сам перезапускает сервер при изменении файлов.

2. Клиент: открыть файл `client/index.html` в браузере (двойным щелчком).

Отдельные запросы удобно проверять через файл `server/requests.http` (расширение REST Client для VS Code) или через Postman.

## Структура

```
server/
  index.js            запуск сервера, подключение маршрутов
  routes/             адреса API: какой запрос какой функцией обрабатывается
    pets.js
    vets.js
  controllers/        обработчики запросов: проверка данных и ответ
    petsController.js
    vetsController.js
  data/               хранение данных и функции работы с ними
    pets.js
    vets.js
  requests.http       готовые запросы для проверки
client/
  index.html          разметка
  style.css           оформление
  script.js           запросы к API и вывод данных на страницу
```

## API

| Метод | Адрес | Что делает |
|---|---|---|
| GET | /pets | все питомцы |
| GET | /pets/:id | один питомец |
| POST | /pets | добавить `{ name, species, breed?, birthDate? }` |
| PUT | /pets/:id | изменить питомца |
| DELETE | /pets/:id | удалить питомца |
| GET | /vets | список врачей, фильтр `?specialization=терапевт` |
| GET | /vets/:id | один врач |

## Коды ответов

- `200` — всё хорошо
- `201` — создано (новый питомец)
- `400` — в запросе не хватает данных
- `404` — не найдено
